- **100+ explainer videos**
- **50+ Powersheets** (spreadsheets, templates, checklists, financial models)
- **Project management tool** with Kanban, task assignment, calendar
- **AI tools** for ideation, investor finder, ad copy, incubator finder

Used by 20,000+ startups, 120+ companies launched by Martin (Bell Ventures founder).

## Phase Overview

### SETUP (Tasks 1-25) — "Start with Problems → Assemble Core Team → Collect Ideas → Determine Business Model"
- Tasks 1-10: Problem identification, founding fundamentals, mentorship
- Tasks 11-25: Business model selection, MVP planning, pre-seed fundraising

### LAUNCH (Tasks 26-69) — "Develop MVP → Build Functions → Set Up KPI Reports → Go Live"
- Tasks 26-42: MVP development, legal, branding, seed fundraising
- Tasks 43-69: Operations, tech infra, sales funnel, marketing, KPIs, launch

### SCALE (Tasks 70-100) — "Raise Growth Capital → Build Culture → Learn from Data → Optimize Functions → Best-Practice Company"
- Tasks 70-74: Growth investment, hiring, culture
- Tasks 75-100: KPI reporting, product roadmap, tech scaling, CAC/CLV optimization, OKRs, product-market-fit
